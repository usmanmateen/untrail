Code signing policy

This page explains how Untrail's Windows downloads are produced and signed, who can approve a release, and what Untrail does on the network.

Signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Untrail has applied to the SignPath Foundation program. Releases published before it's in place are unsigned; every release, signed or not, comes with SHA-256 checksums and signed build provenance from GitHub.

What gets signed

  • Untrail.exe, the app, and UntrailSetup.exe, the installer that contains it. Both are built from this repository's source by the project's own GitHub Actions release workflow, on GitHub-hosted runners.
  • Only commits on main are released. Every change reaches main through a pull request that has passed the build, the integration tests, CodeQL, dependency review and a workflow audit.
  • A release starts from a version tag, which can't be moved or deleted. Each signing request is approved by hand before anything is signed.
  • Untrail contains no third-party binaries. Nothing that isn't built from this repository is signed.

Team roles

Committers and reviewers
Usman Mateen. Changes from anyone else are reviewed by a committer before they're merged.
Approvers
Usman Mateen approves each signing request.

Everyone with access to the repository or the signing service uses multi-factor authentication.

Privacy policy

Untrail runs entirely on your PC. It doesn't collect, store or send any information about you, your files or the apps you remove.

  • Update check. At most once a day, Untrail asks GitHub's public releases API (api.github.com/repos/usmanmateen/untrail/releases/latest) whether a newer version exists. The request contains no personal data; like any web request it reveals your IP address to GitHub, and it identifies itself as Untrail with its version number. GitHub's own privacy statement applies to it. Turn it off in Untrail under Settings, then Check for updates automatically, or start Untrail with --no-update-check.
  • Updating. When you choose Update now, Untrail downloads the installer and its checksum file from the GitHub release, and installs it only if the checksum matches.
  • Removal logs and backups are written to Documents\Untrail Backups on your PC and never leave it.
  • This website uses no cookies, analytics or tracking. It's hosted on GitHub Pages, which may log visits as described in GitHub's privacy statement.

Untrail only changes your system when you ask it to remove an app, and it backs up registry entries before deleting them. It installs for your account only and uninstalls completely from Settings, then Apps.

Reporting a problem

Security issues: please report them privately, as described in the security policy. Anything else: open an issue.
